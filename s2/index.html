What I would do on your site

  1. Build this member home as a normal WordPress page with your logo, colours and fonts, so it matches the rest of your site.
  2. Fill it with MemberPress's own parts: the member's name, their active memberships, the account and billing tabs, and content rules so each member sees what their plan opens.
  3. Send every member to this page right after login, from the MemberPress login form and from the normal WordPress login.
  4. Tidy the existing account page so it uses the same look, and test it on phone and desktop with a test member of each plan.

The redirect, in short

MemberPress has a login redirect setting; where a site needs more control (a different home per plan, or admins kept on the dashboard) a small snippet does it:

// Send members to the member home after login
add_filter( 'mepr-process-login-redirect-url', function ( $url, $user ) {
    if ( user_can( $user, 'manage_options' ) ) {
        return $url; // admins keep their usual page
    }
    return get_permalink( get_page_by_path( 'member-home' ) );
}, 10, 2 );
